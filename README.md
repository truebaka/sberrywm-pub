This is basically the ramblings of the creator of this WM.

The core idea is that the desktop is divided into three levels:

* **Basket** — the regular tiling space. This is the familiar layer you'd expect from compositors like Hyprland or Niri.
* **Meadow** — the berries are scattered around, but they all stay within their own area. In practice, each meadow is similar to a workspace, except it exists on an infinite canvas.
* **World** — here you can see every berry from every meadow at once. This is essentially the Mango Overview.
